# 🏆 PROBLEM-SOLVING CHECKLIST

Before considering a problem completely understood:

- ❓ What is the problem asking?
- 💡 What is the brute-force approach?
- ⚡ Can the approach be optimized?
- 🧠 What DSA pattern is being used?
- 💻 Can I implement it correctly?
- 🧪 Have I tested edge cases?
- ⏱️ What is the time complexity?
- 💾 What is the space complexity?
- 🔄 Can I reproduce the solution without looking?
- 🎯 Can I recognize this pattern in another problem?
